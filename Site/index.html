Everything you do with tart, one click away

Tart stays the VM engine. Tart Manager gives your local VMs a Mac interface with safety checks.

▶

Run, suspend, stop

Start a VM, suspend a macOS guest and resume it with no cold boot, stop it gracefully, or force-stop it after you confirm.

＋

Create and clone

Create VMs from OCI images or IPSW restore images, pull images from a registry, import .tvm archives, and clone VMs.

◷

Snapshots

Take a snapshot before you experiment. Restore it or remove it later.

⚙︎

Configure

Change VM resources, hardware identity, and shared folders. Replace the disk of a stopped VM.

☰

Jobs you can watch

See clone, import, export, create, pull, and cleanup jobs with their progress. Cancel a job that you no longer need.

◐

Menu bar and updates

Control common VM actions from the menu bar. The app updates itself and waits until your jobs finish.

Install in a minute

Tart Manager includes tart, so you do not need a separate tart install.

brew install --cask alexandrpkhm/tap/tart-manager

Or install from the DMG:

  1. Download the DMG from the latest release.
  2. Open the DMG and drag Tart Manager to Applications.
  3. Open Tart Manager, choose your VM storage folder (the default is ~/.tart), and run a VM.
First launch: the app is not notarized, so macOS blocks it one time. On macOS 15 or later, open System Settings → Privacy & Security and click Open Anyway. On macOS 14, Control-click the app and choose Open. Later updates install from inside the app with no warning.
